# Electronics Inventory System
A C++ object-oriented inventory management system using OOP and file handling for electronic components.

## Features

- Add components
- Search components
- Remove components
- Sort inventory
- CSV export
- File handling

## Technologies

- C++
- Object-Oriented Programming
- Inheritance
- Polymorphism
- File Handling

## Build

```bash
g++ Main.cpp Component.cpp Resistor.cpp Capacitor.cpp Inductor.cpp InventoryManager.cpp FileHandler.cpp -o inventory
```

## Run

```bash
.\inventory.exe
```
